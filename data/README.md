# Synthetic data only

Every file in `data/`, `input_examples/`, `tests/`, and `demo/` is **fake**.

- Names, companies, invoices, phone last-four digits, and bank last-four digits are invented.
- Domains use the reserved `.example` suffix only. None of them are real websites.
- No real people, real bank accounts, real phone numbers, or real passwords appear here.
- Family “safe words” are never stored. Contacts only record whether a safe word was set (`safe_word_set: true`).
- Use this corpus to test Scam Shield before anyone acts on a payment or a message. It is not live company data.
